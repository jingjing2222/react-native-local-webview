# react-native-local-webview

Serve local web bundles over localhost and render them with react-native-webview

## Installation


```sh
npm install react-native-local-webview
```


## Usage


```js
import { multiply } from 'react-native-local-webview';

// ...

const result = multiply(3, 7);
```
